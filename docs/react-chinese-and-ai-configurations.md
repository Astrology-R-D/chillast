# 命理、节气页面与命名 AI 配置

React 入口 `npm run dev:react` 的「命理分析」和「节气年历」现已接入真实后端，替换占位页面。

## 命理分析

- 从档案库选择出生档案，支持姓名、拼音与首字母搜索。
- 排盘后展示四柱、日主、真太阳时、五行分布、十神、藏干、农历信息与十二时辰；切换档案不会混用上一个档案的数据。
- 「AI 解读」将当前档案与原始八字结果作为独立的 `chinese-chart` 上下文发送；原有判据与引用流程继续使用计算事实。
- 两个新页面支持亮暗主题、窄窗口、加载状态、空状态与失败重试。

八字和农历沿用 `vendor/sxwnl` 后端。适配器现在先将档案的出生地民用时间转换成 UTC，再调用要求格林尼治时间的 `mingLiBaZi`。此前直接传入本地钟表时间会让真太阳时与时柱偏移。用于回归的六盘水档案（2004-07-07 11:15，26.6°N、104.8333°E）得到真太阳时 `10:09:26`、时柱 `乙巳`。十二时辰的当前标记按完整干支匹配，避免同一天干被重复标记。

## 节气年历

默认加载当前年，也会记住最后查询年份。可查询 1–3000 年，按月份显示全部 24 节气及日期、时刻和农历日期，并支持拼音搜索、月份筛选、前后年份和返回今年。交接时刻明确使用北京时间（UTC+8）。

## 命名 AI 配置

在「AI 配置」选择「新建配置」，填写配置名称、服务商、模型和调用参数后保存。选择已保存配置即可应用；可以更新、重命名和删除未启用配置。API Key 随各自配置保留，同一配置更新模型或参数时无须重新输入。更换服务商或接口地址时须使用对应凭据。

启动时，原有配置自动导入为「当前配置」。当前配置选择也会保存，下次启动恢复。配置包含服务商、模型、接口地址、温度、MaxTokens 模式和值、模型上下文及输出上限。知识库、工具、MCP 与阅读排版继续作为应用级设置。

主进程 `AiConfigurationStore` 将配置保存在应用 userData 的 `data/ai-configurations.json`，使用可用的 Electron `safeStorage` 加密；主进程返回给界面的描述只包含 `hasApiKey`，不返回密钥。文件采用临时文件与重命名写入，配置读取损坏时保留原文件并报告错误。AI 生成或上下文压缩过程中不能切换配置，切换期间不能发起新生成或压缩；保存失败时恢复之前的运行配置。

## 验证

- `tests/AiConfigurationStore.test.js`：命名、独立凭据、迁移、重启恢复、损坏文件保护、并发互斥与失败回滚。
- `tests/ChineseReactMigration.test.js`：UTC 转换、真实排盘、年历范围与 AI 上下文。
- React 测试：完整面板、档案切换、搜索筛选、AI 解读和配置切换。
- `npm run smoke:chinese`：在隔离的真实 Electron 窗口内验证计算、preload IPC、主题、布局和配置持久化，不调用外部 AI 服务。界面截图输出到 `tests/screenshots/migration-*.png`。
